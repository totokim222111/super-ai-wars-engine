# v2 실기기 확인

엔진 폴더에서 `npm run dev:lan` 또는 빌드 후 `npm run preview:lan`을 실행한다. 같은 네트워크의 기기에서 표시된 주소의 `/game.html`을 연다. 확인 후 Ctrl+C로 닫는다.

기기·OS·브라우저 버전·주소·팩 id·날짜·결과·재현 순서를 기록한다.

- 가로 화면의 타이틀·새 게임·첫 대화·첫 전투, 세로 회전 안내의 팩 제목.
- 노치·홈 표시줄·주소 표시줄 변화 뒤 화면과 터치 좌표.
- 이름 입력·모든 타입과 계열·선택지·이동·공격·스크롤.
- 첫 입력 뒤 음원, 설정 변경과 새로고침 뒤 유지.
- 자동 저장·중단·이어하기·슬롯·내보내기/가져오기·잘못된 파일 거절.
- 같은 주소에서 다른 팩의 설정·슬롯 분리.
- `/v2.html?pack=<id>`의 진열장·어셋 도감.
- 앱 전환·잠금·복귀와 장시간 플레이의 발열·프레임.

자동 검수는 설치된 Chromium에서 실제 팩·첫 전투·진열장과 IndexedDB 이름공간을 확인한다. 결과·캡처는 `tools/out/split/`다. 실제 iOS Safari·Android·장시간 발열은 이번 작업에서 확인하지 않았다. 현재 v2에는 v1 PWA·오프라인·워커 업데이트 기능이 없다.

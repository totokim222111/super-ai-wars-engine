# 작은 산책

2화 오리지널 예제. 선택지→호감도 조건, 배리어·폼·통행 토글, 승리·인터미션·엔딩을 보여 준다. 대본의 주석을 따라 id·수치·그림을 바꿔 시작한다.

그림 파일은 중립적인 주인공·기체·자코·배경을 재사용했다. 루프는 로고 없는 카메라 드론과 그 초상이다. 음악·효과음은 audio/LICENSES.md의 CC0 자료만 사용한다.
## 밸런스 기능 견본

모험가는 추론 130으로 두 번 행동하고, 각성을 예약하면 한 번 더 행동합니다. 정신기 메뉴에서 메아리를 고르면 별도 SP로 보급을 씁니다. 루프의 기체에는 출격당 8회 보급·수리 장치와 에너지 회복이 있습니다.

1화 뒤 상점에서 순환 전지·예비 전지·탄약 상자를 사서 장착할 수 있습니다. 2화의 산책의 합주는 모험가·루프·점이 이어 붙어 있고 루프 호감이 1 이상이면 쓸 수 있습니다. 엔딩 뒤 이어하기는 2회차를 시작합니다. 문법은 `docs/v2-content-pack.md`의 밸런스 기능 절을 참고하세요.
